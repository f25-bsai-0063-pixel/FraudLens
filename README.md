# FraudLens
Credit card fraud detection using Decision Tree and KNN (Programming for AI)

## Dataset

We use the Credit Card Fraud Detection dataset (ULB, via Kaggle):
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

The file is too large for GitHub (~144 MB), so it is not included in this repo.
To run the project:
1. Download `creditcard.csv` from the link above.
2. Place it in the `data/` folder.

284,807 transactions, 31 columns (Time, V1–V28, Amount, Class). Only 492 are fraud (0.17%).
